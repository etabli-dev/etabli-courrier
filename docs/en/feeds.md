---
title: "Feeds"
---

Add an HTTPS RSS/Atom URL and select Refresh local feeds. Tap a subscription, then an article, to read cached text. Failed feeds report an error while retaining cached content. Nextcloud News refreshes through Accounts when the server app is enabled. Read state is local; automatic polling and server read-state mirroring are deferred.

See [current implementation and source-build commands](../current-status.qmd). These pages describe the unpublished October 2026 source revision, not the existing development APK.

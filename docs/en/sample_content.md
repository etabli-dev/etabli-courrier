---
title: "First-launch sample content"
---

A fresh database receives one local account, five bundled 2026 holiday events, two welcome/checklist notes and the project’s GitHub Atom release feed. Installing the sample is one transaction: a failed asset read leaves the database unchanged and can be retried. Existing accounts prevent reseeding, so the installer does not overwrite user content.

The production app does not seed demo mail or provide a Reset-all action. The separate screenshot/demo harness is not the normal application. Feed articles are fetched only after an explicit refresh. Notes and the calendar sample can be used without an account or network.

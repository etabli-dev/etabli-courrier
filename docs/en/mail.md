---
title: "Mail"
---

Connect IMAP in Accounts using autoconfiguration or explicit TLS/STARTTLS settings. Refresh fetches the latest 100 envelopes per folder. Open a message to download its body; cached content remains available offline. Remote HTML is displayed through the existing sanitized text rendering path. A server mailbox identity change preserves the previous cache in a local archive. Sending, full mailbox administration, attachment opening and background IDLE are not exposed in this production UI.

See [current implementation and source-build commands](../current-status.qmd). These pages describe the unpublished October 2026 source revision, not the existing development APK.

---
title: "Accounts and settings"
---

Use Accounts to connect a canonical HTTPS Nextcloud base URL, username and app password, or configure secure IMAP access. Incoming access is verified before the account is enabled. Passwords use platform secure storage. Refresh is manual; Disconnect retains cached records. Reconnect using the same server and username. Settings supports platform-authenticated app lock and non-sensitive preference JSON import/export; that JSON is not a content backup.

See [current implementation and source-build commands](../current-status.qmd). These pages describe the unpublished October 2026 source revision, not the existing development APK.

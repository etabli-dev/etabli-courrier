The OAuth provider is an implementation seam, not an available production account type. Activation requires a project-owned public-client registration, tenant policy review, device redirect/sign-in/refresh testing and a usable production interface. Do not reuse another application’s client ID. Existing mocked provider tests do not verify an Exchange Online account. No current service-retirement timeline is asserted here.

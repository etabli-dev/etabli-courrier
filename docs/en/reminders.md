---
title: "Reminders"
---

The screen lists upcoming saved event reminders and task deadlines. Allow notifications and Reload to rebuild the schedule. Database/scheduling failures preserve existing alarms. Device-local time-zone identifiers and calendar arithmetic are used; Android falls back to inexact scheduling when exact-alarm access is denied. Delivery after reboot, background restrictions and device time-zone changes require physical-device testing. The scheduler does not promise notifications for every expanded recurring event.

See [current implementation and source-build commands](../current-status.qmd). These pages describe the unpublished October 2026 source revision, not the existing development APK.

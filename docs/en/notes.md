Create a note, select a notebook, edit text or checklist content, save and reopen it. A save failure retains the draft. Favorites and per-note locking are available. Locked notes require device authentication before opening; this is an access guard, not database or server encryption. Nextcloud Notes sync runs explicitly from Accounts. Conflicts retain local work and can be preserved as offline copies from Pending edits / recovery.

See [current implementation and source-build commands](../current-status.qmd). These pages describe the unpublished October 2026 source revision, not the existing development APK.

## Desktop keyboard controls

In Notes, press **Ctrl+N** (Windows/Linux) or **⌘N** (macOS) to open the same new-note editor as the New note button. Choose the notebook when prompted, then save normally. The shortcut does not bypass note locking or secure-storage checks.

Across the main workspace, **Ctrl/⌘+1–7** switches between mail, calendar, contacts, tasks, reminders, notes and feeds. **Ctrl/⌘+,** opens Settings, **Ctrl/⌘+Shift+A** opens Accounts, and **F1** shows shortcut help. Wide windows also expose a Keyboard shortcuts button. Text editing keeps its normal character and selection behavior.
